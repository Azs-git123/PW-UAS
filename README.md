# 📋 Manajemen Tugas

**Manajemen Tugas** adalah aplikasi web yang dibuat untuk memenuhi **Ujian Akhir Semester (UAS) Pemrograman Web**. Aplikasi ini dirancang untuk membantu pengguna mencatat dan mengelola tugas dengan lebih mudah dan terorganisir.

Aplikasi dilengkapi dengan sistem **Sign Up dan Login**, sehingga setiap pengguna dapat memiliki akun dan mengelola tugasnya masing-masing.

## ✨ Fitur

* 🔐 **Sign Up** — Membuat akun pengguna baru.
* 🔑 **Login** — Masuk ke dalam aplikasi menggunakan akun yang telah dibuat.
* ➕ **Tambah Tugas** — Menambahkan tugas baru.
* 📋 **Lihat Tugas** — Melihat daftar tugas yang telah dibuat.
* ✏️ **Edit Tugas** — Mengubah informasi tugas.
* 🗑️ **Hapus Tugas** — Menghapus tugas yang tidak diperlukan.
* 🚪 **Logout** — Keluar dari akun pengguna.

## 💻 Teknologi

Aplikasi ini dikembangkan menggunakan:

* **HTML** — Struktur halaman website.
* **CSS** — Tampilan dan desain website.
* **JavaScript** — Interaksi pada halaman website.
* **Flask** — Backend aplikasi web.
* **MySQL** — Penyimpanan dan pengelolaan data.

## 🎯 Tujuan

Project ini dibuat sebagai implementasi materi yang telah dipelajari pada mata kuliah **Pemrograman Web**, khususnya dalam pembuatan aplikasi web dinamis, pengelolaan database, autentikasi pengguna, dan penerapan operasi **CRUD (Create, Read, Update, Delete)**.
